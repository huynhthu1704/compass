## What we want
The Product Owner improves one part of an agent proposal by quoting it and asking, in under 15 seconds and without losing the rest (today: reject the run and start a new one from scratch).

_Business need as the Product Owner wrote it:_ If I interact with Claude for building a feature inside a chat conversation / Cowork, I can quote its response and ask for more details or revision. Could you please make the same experience inside Compass.

## Why
An agent proposal can only be approved, or rejected with a reason that ends the run. Changing one line means a new run from scratch, losing the good parts.

## Constraints
- Quoted text could carry prompt-injection text: it is data, scanned by the injection guardrail
- Token cost of follow-ups: send the proposal and quotes, not the whole repository
- No new libraries, no server

## Success measure
Time from reading an answer to sending a quoted question: copy-paste into a new run → under 15 s; items not quoted that change in a revision: unknown → 0.

## Out of scope
- Quoting in GitHub pull-request reviews or outside an agent run
- Branching conversations
- Editing a proposal by hand inside the run

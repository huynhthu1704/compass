# Intent: Version number and version history

Status: Approved (idea brief approved in the Compass portal)
Requested: 2026-11-28 for feature F-022, in the Compass portal

_Generated from `compass/spec.json → features[F-022].idea`. Edit the idea there or in the portal, not this file._

## What we want
Everyone using the Compass portal can see which version is live and what changed in each version, the way Bee There shows it (today: no version number anywhere in the portal).

_Business need as the Product Owner wrote it:_ add version tracking number for this portal — then: add version history similar to 'bee there' https://beetheremap.com/#/

## Why
Nothing in the portal says which version is live, so nobody can tell whether a fix has been deployed or what changed since their last visit.

## Constraints
- No change to the deploy workflow (protected path): build number from GitHub Actions variables
- Honey tokens only, light and dark mode; no new libraries
- Phone menu and keyboard keep working

## Done when
Done when the bottom of the sidebar shows the version line (release, build number, commit) and clicking it opens What's new with every release, newest first, the current one marked.

## Out of scope
- Git tags and GitHub Releases
- Images in release entries
- Vietnamese text
- Version history for the projects Compass manages
- The "new version available" notice (F-021)

## Requirements
- REQ-111 — The sidebar shows the portal's version and build
- REQ-112 — What's new lists every portal release

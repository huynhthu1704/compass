# Intent: Collapsible agent trace

Status: Approved (idea brief approved in the Compass portal)
Requested: 2026-11-27 for feature F-017, in the Compass portal

_Generated from `compass/spec.json → features[F-017].idea`. Edit the idea there or in the portal, not this file._

## What we want
The Product Owner reaches an agent's proposal and the approval buttons without scrolling past its step-by-step trace (today: the full trace of ~15–40 lines always sits above the proposal).

_Business need as the Product Owner wrote it:_ allow user to collapse the detailed steps inside (the trace box of an agent run)

## Why
Every agent run shows its whole trace (model turns, tool calls, results) above the proposal, so reviewing a run means scrolling through technical steps first.

## Constraints
- Nothing hidden for good: one click shows the full trace
- Keyboard and screen-reader friendly
- Honey tokens only; no new libraries

## Done when
Lines of trace shown above the proposal of an awaiting-approval run: all steps → one summary line (test + screenshot).

## Out of scope
- Remembering the choice between visits
- Folding other cards (guardrails, change set)

## Requirements
- REQ-045 — The agent trace can be folded and unfolded

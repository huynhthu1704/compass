# Intent: Team floor: watch the agent team work, live

Status: Approved (idea brief approved in the Compass portal)
Requested: 2026-11-26 for feature F-009, in the Compass portal

_Generated from `compass/spec.json → features[F-009].idea`. Edit the idea there or in the portal, not this file._

## What we want
From the Team floor alone, the Product Owner can tell within 5 seconds which agent is working, on which feature, and whether anything waits for her approval (today: only one run log at a time).

_Business need as the Product Owner wrote it:_ recently, I see a few AI users they built a few creative team working with each other in a realtime movement user interface. Can we apply this for compass

## Why
The pipeline is already a team with handoffs and approval gates, but the portal shows it as separate text logs, so who is working, who waits for whom and where a feature is stuck are hard to see.

## Constraints
- A view only: drawn from the run trace already recorded; no change to agents, tools, guardrails or gates
- No extra Claude calls or tokens, no paid service, no new libraries
- Live means live in the browser tab that runs the agents

## Success measure
Time to answer "who is working, on what, and is anything waiting for me?": open each run (minutes) → one glance at the Team floor (≤ 5 seconds).

## Out of scope
- Agents talking to each other
- Several viewers on several devices (needs a server)
- Sound, custom avatars, a game-like world

## Requirements
- REQ-005 — The Team floor shows every agent at its desk with its current state
- REQ-006 — What each agent is doing appears live in its speech bubble and the activity list
- REQ-007 — Handoffs move as cards between desks, and a failed review sends the card back
- REQ-008 — Approvals can be given from the Team floor with the same result as from Agent runs
- REQ-009 — The Team floor respects reduced motion, works on a phone and in demo mode, at no extra cost

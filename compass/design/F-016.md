## Approach
The agent run page gets a conversation. Selecting text inside the answer (summary, idea brief, requirements, screens, test cases, files) shows a dark "❝ Quote" button next to the selection; every item also has a "❝ Quote" pill that quotes it whole. Quotes land in a "Reply to the agent" box under the proposal as honey quote blocks naming their source (REQ-002 · AC 2), each with ×. The box has Revise → vN (primary) and Ask (secondary). The run then shows a Conversation column (your messages with quotes, agent answers with tokens, green "Proposal v2 — changed: …" markers), a v1 / v2 · latest picker in the header and a compare view: changed items with removed (red) and added (mint) lines, unchanged items folded. The approval card names the version it applies. On phones a long-press menu offers Quote and the reply box becomes a bottom sheet.

### SCR-1 · Desktop · Quote from an agent run
**Elements:** "❝ Quote" button next to a selection inside the answer; "❝ Quote" pill on each requirement / screen / test case / file; Reply box: quote blocks with source and ×, message field, Revise → vN (primary), Ask (secondary) with a one-line hint; Trace column without quoting; Approval card below

**States:** no selection; text selected; 2 quotes + message; empty reply: buttons disabled (SCR-4 D)

### SCR-2 · Desktop · Conversation, versions and compare
**Elements:** Conversation column: You · Ask / You · Revise messages with quotes and time, agent answers with tokens; "Proposal v2 — changed: …" marker with Compare link; Guardrail line for the quotes; Version picker v1 / v2 · latest in the run header; Compare view: changed items with red removed and mint added lines, unchanged items folded; Approval card "Approve v2"

**States:** one version (no picker); several versions, latest selected; earlier version selected (read-only, "latest" badge on v2); compare on / off

### SCR-3 · Phone · Long-press to quote, reply sheet
**Elements:** Long-press selection menu with Copy · ❝ Quote · Select all; 44 px Quote icon per item; Bottom reply sheet with grabber, quote count, quote blocks, message, Ask and Revise full width

**States:** selection menu open; sheet with 2 quotes; sheet above the keyboard

### SCR-4 · States · code run, approved run, warning, empty, working
**Elements:** A: file row with "❝ Quote file" and a line-range quote; only quoted files are re-proposed; B: approved run — Revise disabled, "Already applied — start a new run"; rejected runs can be revised; C: red prompt-injection warning for quoted instructions; D: empty reply — both buttons disabled; E: agent answering — buttons disabled; demo answers instantly

**States:** code run; approved; rejected; warning; empty; working

## Notes
Accessibility: every Quote pill and the selection button are buttons reachable with Tab and Enter; the reply box gets the focus after quoting; the selection button is shown only for a selection fully inside the answer of a finished run (never in the trace). Phone: tap targets ≥ 44 px, sheet stays above the keyboard. Reuses Button, Badge, honey colour variables and text styles; no new components. Demo mode answers instantly with fixed text. No extra Claude call unless Ask or Revise is pressed.

## Coverage
Every approved requirement is covered by at least one screen.

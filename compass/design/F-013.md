## Approach
The 248 px sidebar is split into three groups by thin lines: the workspace links (Projects, Agent architecture), the open project, and an account footer pinned to the bottom. Every page link starts with an 18 px stroke icon; the current page is honey with a 3 px brand bar on the left. The open project is a card (letter avatar, name, sync state with a coloured dot, chevron) that leads to the project list; under it Feature board, Team floor (the only approval count, a honey pill), Agent runs, Release and Knowledge. "Features" has a count; each feature row has a stage-coloured dot, the name on up to two lines and the short id (F01) on the right; the open feature lists its five stages indented with step numbers or ✓. The footer is an account card (initial, @user, "GitHub connected" or "Demo mode · connect") that opens Connections, then the role picker and one sun/moon theme button.

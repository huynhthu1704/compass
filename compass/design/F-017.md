## Approach
The trace card of an agent run gets a header row: a ▸/▾ chevron, the overline, the step count, a red "N failed" chip when steps failed, and a "Show steps" / "Hide steps" button. The card starts folded (header only) when the run is awaiting approval, approved, rejected, failed or done, so the proposal and approval buttons sit right below it; it starts open while the agent is running. The Product Owner's own toggle is kept when the status changes. Each step still expands its own details.

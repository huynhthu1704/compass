## Approach
Two small changes inside the honey design system. Status labels: Draft uses the neutral tone (grey), Approved uses the success tone (mint, like Done), In build stays info (sky), on requirements, test cases and features. Phone stage strip: below 720 px the six stage cards of a feature page become a one-per-row list in stage order (stage chip, stage name, summary, agent · role, chevron); the current stage is highlighted honey. 720 px and wider stays as today.

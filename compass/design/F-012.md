## Approach
A "Delete feature" button sits next to "Archive feature" on the feature page and opens a centred dialog (full-width sheet on phones). The dialog lists what will be removed — requirements with their status, test cases, the three F-xxx.md files and the open GitHub issues that will be closed as not planned — and asks to type the feature id. Delete (red) is enabled only when the text is exactly the id. A built feature gets a red warning box above the list, naming the requirements In build or Done and its open pull requests, which stay open. After deleting, the feature board shows a notice: mint when every issue closed, honey with links when GitHub refused some.

### SCR-1 · Desktop · Delete dialog, feature without code
**Elements:** Title "Delete F-xxx · name?" and the Archive hint; "What will be removed": requirements with status badges, test cases, files, open issues; Field "Type F-xxx to confirm"; Cancel (secondary) and Delete feature (red)

**States:** Id typed exactly → Delete enabled; Esc or Cancel → closes, nothing changes

### SCR-2 · Desktop · Delete dialog, feature with code
**Elements:** Red warning box naming the built requirements; Open pull requests with links, marked "stays open"; Hint "Delete stays off until the text is exactly F-xxx"; Delete feature disabled (grey)

**States:** Text does not match → Delete disabled; No code and no open PR → no warning box (SCR-1)

### SCR-3 · Phone · Dialog and result notice
**Elements:** Short summary of what will be removed; Full-width Delete feature and Cancel buttons; Honey notice listing issues GitHub refused, with link and reason; Mint notice when every issue was closed

**States:** Some issues still open (403: token needs Issues: Read & write); All issues closed; Demo project: deleted locally

## Notes
Keyboard: focus starts in the id field, Tab cycles inside the dialog, Esc cancels. The dialog scrolls inside itself on short screens. Text colours from the honey tokens only; the red Delete button uses text/danger with white text (contrast checked in build).

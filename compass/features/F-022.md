# F-022 · Version number and version history

**Business intent:** Everyone using the Compass portal can see which version is live and what changed in each version, the way Bee There shows it (today: no version number anywhere in the portal). · [intent](../intent/F-022.md) · [design](../design/F-022.md)

## Problem
Nothing in the portal says which version is live, so nobody can tell whether a fix has been deployed or what changed since their last visit.

## Users
- Product Owner
- Everyone using the portal

## Done when
Done when the bottom of the sidebar shows the version line (release, build number, commit) and clicking it opens What's new with every release, newest first, the current one marked.

## In scope
- Version line under the sidebar account card
- What's new list of releases grouped by day
- Dot for a release not opened yet (kept in the browser)
- Test that package.json's version has a history entry

## Out of scope
- Git tags and GitHub Releases
- Images in release entries
- Vietnamese text
- Version history for the projects Compass manages
- The "new version available" notice (F-021)

## Risks
- No change to the deploy workflow (protected path): build number from GitHub Actions variables
- Honey tokens only, light and dark mode; no new libraries
- Phone menu and keyboard keep working

## Requirements
- **REQ-111** The sidebar shows the portal's version and build — Draft (Should)
- **REQ-112** What's new lists every portal release — Draft (Should)

## Test cases
- **TC-511** The version line shows release, build number and commit, or dev → REQ-111 · Not run
- **TC-512** What's new lists the releases newest first, marks the current one and clears the new-release dot → REQ-112 · Not run

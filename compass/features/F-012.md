# F-012 · Delete a feature and close its GitHub issues

**Business intent:** A feature added by mistake is gone from the portal, the spec and the repo in under 30 seconds, and its GitHub issues are closed as not planned (today: archive only; removing one means hand-editing spec.json and closing issues one by one). · [intent](../intent/F-012.md) · [design](../design/F-012.md)

## Problem
A feature can only be archived. A mistaken or duplicate feature stays on the board and in spec.json for good, and its requirement issues stay open on GitHub.

## Users
- Product Owner

## Outcome metric
Time to remove a feature: hand-editing spec.json and closing each issue → one dialog under 30 s; open issues of a deleted feature: all → 0 (or a list of the ones GitHub refused).

## In scope
- Delete button and typed-id confirmation on the feature page
- Removing the feature, its requirements, test cases, agent runs and generated files
- Closing its open GitHub issues as not planned, with a comment
- A strong warning when the feature has code

## Out of scope
- Permanently deleting GitHub issues
- Removing code, tests, branches or pull requests of a built feature
- An undo or trash bin (Archive stays the reversible option)

## Risks
- Deletion cannot be undone in the portal: typing the feature id is the human approval
- The token needs Issues: Read & write
- No new libraries, no server

## Requirements
- **REQ-016** Delete a feature from its page after typing its id — Approved (Must)
- **REQ-017** Deleting a feature removes everything that belongs to it — Approved (Must)
- **REQ-018** The deleted feature's open GitHub issues are closed as not planned — Approved (Must)
- **REQ-019** A strong warning before deleting a feature that has code — Approved (Should)

## Test cases
- **TC-029** Delete is enabled only after typing the exact feature id → REQ-016 · Not run
- **TC-030** Cancel and Esc change nothing; Delete returns to the board → REQ-016 · Not run
- **TC-031** Delete dialog on a phone and by keyboard → REQ-016 · Not run
- **TC-032** Spec clean-up removes the feature, its requirements, tests and runs → REQ-017 · Not run
- **TC-033** One commit deletes only the feature's files that exist → REQ-017 · Not run
- **TC-034** Demo projects delete locally only → REQ-017 · Not run
- **TC-035** Issue matching selects only the feature's open issues → REQ-018 · Not run
- **TC-036** Issues are commented and closed as not planned; failures are listed → REQ-018 · Not run
- **TC-037** Warning only for built features or open pull requests → REQ-019 · Not run

# F-017 · Collapsible agent trace

**Business intent:** The Product Owner reaches an agent's proposal and the approval buttons without scrolling past its step-by-step trace (today: the full trace of ~15–40 lines always sits above the proposal). · [intent](../intent/F-017.md) · [design](../design/F-017.md) (Approved)

## Problem
Every agent run shows its whole trace (model turns, tool calls, results) above the proposal, so reviewing a run means scrolling through technical steps first.

## Users
- Product Owner
- Everyone approving agent runs

## Outcome metric
Lines of trace shown above the proposal of an awaiting-approval run: all steps → one summary line (test + screenshot).

## In scope
- The trace card of an agent run on the stage pages, Build and Agent runs

## Out of scope
- Remembering the choice between visits
- Folding other cards (guardrails, change set)

## Risks
- Nothing hidden for good: one click shows the full trace
- Keyboard and screen-reader friendly
- Honey tokens only; no new libraries

## Requirements
- **REQ-045** The agent trace can be folded and unfolded — Approved (Should)

## Test cases
- **TC-090** Trace folded by default once the run stops working; toggle switches it → REQ-045 · Not run

# F-020 · Quote an agent answer and ask for details or a revision

**Business intent:** The Product Owner improves one part of an agent proposal by quoting it and asking, in under 15 seconds and without losing the rest (today: reject the run and start a new one from scratch). · [intent](../intent/F-020.md) · [design](../design/F-020.md) (Approved)

## Problem
An agent proposal can only be approved, or rejected with a reason that ends the run. Changing one line means a new run from scratch, losing the good parts.

## Users
- Product Owner
- BA / UX / QA / Dev reviewing agent proposals

## Outcome metric
Time from reading an answer to sending a quoted question: copy-paste into a new run → under 15 s; items not quoted that change in a revision: unknown → 0.

## In scope
- Quote selected text or a whole item of any agent run
- Ask: the agent answers, the proposal is unchanged
- Revise: a new proposal version that changes only what was quoted
- Proposal versions with a compare view; Approve applies the latest
- The conversation is kept with the run; demo mode works

## Out of scope
- Quoting in GitHub pull-request reviews or outside an agent run
- Branching conversations
- Editing a proposal by hand inside the run

## Risks
- Quoted text could carry prompt-injection text: it is data, scanned by the injection guardrail
- Token cost of follow-ups: send the proposal and quotes, not the whole repository
- No new libraries, no server

## Requirements
- **REQ-050** Quote any part of an agent run — Approved (Must)
- **REQ-051** Ask the agent about the quoted text — Approved (Must)
- **REQ-052** Revise the proposal from the quoted text — Approved (Must)
- **REQ-053** Proposal versions and compare — Approved (Should)
- **REQ-054** The conversation is kept with the run, safely — Approved (Should)

## Test cases
- **TC-090** A quote keeps the selected text and names its source → REQ-050 · Not run
- **TC-091** Quote button only for selections inside a finished answer → REQ-050 · Not run
- **TC-092** Quoting on a phone and by keyboard; removing a quote → REQ-050 · Not run
- **TC-093** Ask adds an answer and leaves the proposal unchanged → REQ-051 · Not run
- **TC-094** The follow-up prompt carries goal, proposal, conversation and quotes as data → REQ-051 · Not run
- **TC-095** Ask and Revise are disabled for an empty reply → REQ-051 · Not run
- **TC-096** A revision changes only the quoted items and keeps their ids → REQ-052 · Not run
- **TC-097** Revising code re-proposes only the quoted files → REQ-052 · Not run
- **TC-098** Revision re-runs checks; rejected runs reopen; approved runs cannot be revised → REQ-052 · Not run
- **TC-099** The version marker names what changed → REQ-053 · Not run
- **TC-100** Approve applies the latest version → REQ-053 · Not run
- **TC-101** Compare with the previous version → REQ-053 · Not run
- **TC-102** Quoted instructions are wrapped as data and flagged → REQ-054 · Not run
- **TC-103** The conversation survives a reload and goes away with its run → REQ-054 · Not run

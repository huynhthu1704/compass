# F-009 · Team floor: watch the agent team work, live

**Business intent:** From the Team floor alone, the Product Owner can tell within 5 seconds which agent is working, on which feature, and whether anything waits for her approval (today: only one run log at a time). · [intent](../intent/F-009.md) · [design](../design/F-009.md) (Approved)

## Problem
The pipeline is already a team with handoffs and approval gates, but the portal shows it as separate text logs, so who is working, who waits for whom and where a feature is stuck are hard to see.

## Users
- Product Owner
- Delivery Manager
- Anyone watching a demo

## Outcome metric
Time to answer "who is working, on what, and is anything waiting for me?": open each run (minutes) → one glance at the Team floor (≤ 5 seconds).

## In scope
- Team floor page with the 7 agents at desks
- Live speech bubbles and activity list
- Handoff cards and rework path
- Approve from the floor
- Reduced motion, phone layout, demo mode

## Out of scope
- Agents talking to each other
- Several viewers on several devices (needs a server)
- Sound, custom avatars, a game-like world

## Risks
- A view only: drawn from the run trace already recorded; no change to agents, tools, guardrails or gates
- No extra Claude calls or tokens, no paid service, no new libraries
- Live means live in the browser tab that runs the agents

## Requirements
- **REQ-005** The Team floor shows every agent at its desk with its current state — In build (Must)
- **REQ-006** What each agent is doing appears live in its speech bubble and the activity list — In build (Must)
- **REQ-007** Handoffs move as cards between desks, and a failed review sends the card back — In build (Should)
- **REQ-008** Approvals can be given from the Team floor with the same result as from Agent runs — In build (Must)
- **REQ-009** The Team floor respects reduced motion, works on a phone and in demo mode, at no extra cost — In build (Must)
- **REQ-020** Each waiting item says what it is and how long it has waited — Approved (Must)
- **REQ-021** The approval desk stays compact, with a link to all waiting runs — Approved (Must)
- **REQ-022** Details of a waiting item open in a side panel — Approved (Should)

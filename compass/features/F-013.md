# F-013 · Sidebar navigation: grouped, scannable and keyboard friendly

**Business intent:** Any role finds a page, the open project's state and the settings in the sidebar at a glance (today: text-only links, the approval count shown twice, jargon, cut-off feature names, a crowded footer and no keyboard focus). · [intent](../intent/F-013.md) · [design](../design/F-013.md) (Approved)

## Problem
The sidebar is a plain list of text links with a large empty gap; the same approval count shows on Team floor and Agent runs; "Knowledge (RAG)" is jargon; feature names are cut off; the footer mixes Connections, the role and two theme buttons; keyboard users see no focus.

## Users
- Product Owner
- Business Analyst
- Delivery Manager
- Designer
- Developer
- QA
- Ops

## Outcome metric
Before/after screenshots approved by the Product Owner; approval count shown 2 times → 1; sidebar items with a visible keyboard focus: 0 → all.

## In scope
- Icons and three groups (workspace, project, account)
- Project card with sync state
- One approval count on Team floor
- Readable feature list
- Account footer with one theme button
- Visible keyboard focus

## Out of scope
- Collapsible icon-only sidebar
- Project switcher drop-down
- Search
- Redesign of the pages

## Risks
- Honey tokens only, light and dark mode
- No new libraries
- Phone menu must keep working

## Requirements
- **REQ-070** The sidebar is grouped, has icons and shows the open project as a card — Approved (Must)
- **REQ-071** The approval count shows once, on Team floor — Approved (Must)
- **REQ-072** The feature list is readable — Approved (Should)
- **REQ-073** The account footer shows the connection, the role and one theme button — Approved (Should)

## Test cases
- **TC-400** Sidebar groups, icons, project card and link order → REQ-070 · Not run
- **TC-401** Keyboard focus is visible in the sidebar → REQ-070 · Not run
- **TC-402** The approval count appears once → REQ-071 · Not run
- **TC-403** Feature rows: count, dot, two-line name, id and tooltip → REQ-072 · Not run
- **TC-404** Account footer and single theme button → REQ-073 · Not run
- **TC-405** Sidebar on desktop and phone, light and dark → REQ-070, REQ-072, REQ-073 · Not run

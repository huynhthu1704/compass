# F-010 · Honey brand: Compass shares the Bee There look

**Business intent:** 100% of the portal's pages use the Bee There honey theme in light and dark mode, with no old teal colour left in the code (today: 0%, all teal). · [intent](../intent/F-010.md) · [design](../design/F-010.md) (Approved)

## Problem
Compass and Bee There look like unrelated products; the new Team floor design is already drawn in the honey brand.

## Users
- Product Owner
- Everyone using the portal

## Outcome metric
Pages on the honey theme: 0% → 100%; old teal colours in src/: many → 0 (checked by a test).

## In scope
- Colour tokens (light + dark)
- Type: Lexend headings
- Shapes: pill buttons, rounded cards, warm shadows
- Logo
- Every page

## Out of scope
- New pages or layouts
- Changing Bee There
- A shared token package between the repos

## Risks
- Change through the tokens in src/index.css, not page by page; no new libraries
- Normal text keeps WCAG AA contrast (4.5:1) in both modes
- Nothing else changes: same pages, same behaviour

## Requirements
- **REQ-010** Compass colours follow the honey design system in light and dark mode — In build (Must)
- **REQ-011** Compass type, shapes and logo follow the honey design system — In build (Must)
- **REQ-012** No page keeps the old teal theme — In build (Must)
